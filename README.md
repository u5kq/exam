# folio.exam

高校入試に必要な情報・成績・模試・予定・出願準備を整理する、folioブランドのレスポンシブWebアプリです。

公開URL: https://u5kq.github.io/exam/

## 現在の実装
- ホームダッシュボードと受験ポートフォリオ
- 高校候補の登録・一覧・検索・比較
- 第一志望・併願校・安全校・検討中の役割設定
- 9教科の評定入力と入試シミュレーター
- 5教科模試の記録・履歴・学力分析
- 学習タスク・集中タイマー
- 出願管理・オンライン出願入力練習（練習専用）
- 書類チェック・受験予定・面接作文・過去問記録
- 公式情報・出典メモ、データのバックアップ
- iPhone / iPad / PC向けレスポンシブUI
- オリジナルSVGロゴ、folio IDログイン画面UI、プライバシー・利用・安全ポリシー画面

## 認証・データ保存について
- ログインボタンとログイン画面はUIとして設置していますが、認証基盤との接続は未実装です。ログインはできません。
- 入力データは現在、利用中のブラウザの localStorage に保存されます。端末間同期・クラウド保存は未実装です。
- 実在の個人情報やパスワードを入力しないでください。出願練習は架空情報で行ってください。

## 情報の正確性・出願について
- 高校情報、募集要項、選抜基準、日程、学費は年度や学校により変わります。必ず自治体・学校の最新公式情報を確認してください。
- 合格可能性の確率予測や公式な合否判定は行いません。
- オンライン出願練習は入力練習用であり、実際の出願送信・決済は行いません。
- 実際の出願条件・締切・必要書類は、必ず学校や自治体の公式案内および先生・保護者と確認してください。

## 開発方針
既存データを不用意に削除せず、正確性・根拠の明示・個人情報保護・端末間の一貫性を優先します。未実装機能を実装済みと表示せず、学校情報には出典・確認日・対象年度を持たせる方針です。

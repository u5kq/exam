# folio.exam

高校入試に必要な情報・成績・模試・予定を整理する、folioブランドのレスポンシブWebアプリです。

公開予定URL: https://u5kq.github.io/exam/

## 現在の実装（初期版）
- ホームダッシュボード
- 高校候補の登録・一覧・公式サイトリンク
- 9教科の評定入力と合計表示
- 5教科模試の記録・履歴・合計点
- 最新模試の教科別スコア表示
- 受験関連予定の登録・一覧
- iPhone / iPad / PC向けレスポンシブUI
- ブラウザの localStorage による端末内保存

## 重要な注意
- 保存データは現在のブラウザ・端末内に保存されます。別端末への同期やログイン機能は未実装です。
- 高校情報・入試日程・選抜基準の全国データベースは未搭載です。必ず各自治体・学校の公式情報で確認してください。
- 合格可能性の確率予測や公式な合否判定は行いません。
- 出願情報の入力練習や書類管理、AI/OCR機能は今後の開発対象です。
- 実際の出願送信・決済は行いません。

## 公開方法
GitHub Pages の設定で Deploy from a branch を選択し、Branch を main、Folder を / (root) にして保存してください。

## 開発方針
正確性・根拠の明示・個人情報保護・端末間の一貫性を優先します。未実装機能を実装済みと表示せず、学校情報には出典・確認日・対象年度を持たせる方針です。
